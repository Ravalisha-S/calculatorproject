Simple Calculator

A simple and interactive calculator built using HTML, CSS and JavaScript.

The calculator performs basic arithmetic operations with a clean interface and supports keyboard input for easier use.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear button
- Delete button
- Result button
- Keyboard support
- Error handling for invalid calculations
- Responsive user interface

Technologies Used

- HTML5
- CSS3
- JavaScript

Keyboard Controls

Key| Action
"0-9"| Enter numbers
"+"| Addition
"-"| Subtraction
"*"| Multiplication
"/"| Division
"."| Decimal
"Enter"| Calculate
"Backspace"| Delete
"Escape"| Clear

How to Run

1. Download or clone this repository.
2. Open "Calculator.html" in a web browser.
3. Use the calculator buttons or keyboard to perform calculations.
