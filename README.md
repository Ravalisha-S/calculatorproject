🧮 Simple Calculator

A simple and interactive calculator built using HTML, CSS and JavaScript.

✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal calculations
- 🧹 Clear button
- ⌫ Delete button
- 🟢 Result button
- ⌨️ Keyboard support
- ⚠️ Error handling for invalid calculations
- 📱 Simple and responsive interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

📂 Project Structure

Calculator/
│
├── Calculator.html
└── README.md

🚀 How to Run

1. Download or clone this repository.
2. Open "Calculator.html" in a web browser.
3. Enter numbers using the calculator buttons.
4. You can also use your keyboard for calculations.
5. Press "=" or "Result" to calculate the answer.

⌨️ Keyboard Controls

Key| Action
"0–9"| Enter numbers
"+"| Addition
"-"| Subtraction
"*"| Multiplication
"/"| Division
"."| Decimal
"Enter"| Calculate
"Backspace"| Delete
"Escape"| Clear

This project was created to practice HTML structure, CSS styling and JavaScript functions while building an interactive calculator.
